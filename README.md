# Resume Designing in LaTeX and Word

This repository contains resources and templates for creating professional, ATS-friendly resumes using **LaTeX** and **Microsoft Word**.

---

## 📄 Overview

- **LaTeX Resume**: Ideal for precise formatting, clean typography, and automation.
- **Word Resume**: Easy to edit, widely compatible, and quick to customize.

---

## 🛠 Requirements

### For LaTeX
- [Overleaf](https://www.overleaf.com/) (online) or a local LaTeX distribution like:
  - [TeX Live](https://www.tug.org/texlive/)
  - [MiKTeX](https://miktex.org/)
- A LaTeX editor (TeXstudio, VS Code with LaTeX Workshop, etc.)

### For Word
- Microsoft Word (2016 or later recommended) or Google Docs.
